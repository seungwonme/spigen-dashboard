# Claude의 요금제

![image.png](../../%EC%A0%80%EB%B2%88%EC%A3%BC%20%EB%82%B4%EC%9A%A9%20%EB%B3%B5%EC%8A%B5%20+%20%EA%B3%BC%EC%A0%9C%20%EB%B0%9C%ED%91%9C/%EC%9A%94%EA%B8%88%EC%A0%9C/image.png)

Claude에서는 요금제가 무료, Pro, Max($100/$200)이 있습니다.

바이브 코딩을 본격적으로 하기 위해서 **$100 Max 요금제**가 낫지만, **체험/단발성으로 진행하는 경우에는 Pro 요금제($20) + 추가 사용량 자동 충전으로 진행하는 것도 추천**드립니다.

# 추가 사용량 설정하는 방법

![image.png](../../%EC%A0%80%EB%B2%88%EC%A3%BC%20%EB%82%B4%EC%9A%A9%20%EB%B3%B5%EC%8A%B5%20+%20%EA%B3%BC%EC%A0%9C%20%EB%B0%9C%ED%91%9C/%EC%9A%94%EA%B8%88%EC%A0%9C/image%201.png)

사이드바의 사용자를 누르고 `설정` 창을 열어줍니다.

![image.png](../../%EC%A0%80%EB%B2%88%EC%A3%BC%20%EB%82%B4%EC%9A%A9%20%EB%B3%B5%EC%8A%B5%20+%20%EA%B3%BC%EC%A0%9C%20%EB%B0%9C%ED%91%9C/%EC%9A%94%EA%B8%88%EC%A0%9C/image%202.png)

`사용량` 탭을 누르고 하단의 `추가 사용량` 의 토글을 켜주세요.

그 후 `자동 새로고침 꺼짐` 을 눌러서 자동으로 추가 사용량에 따라 결제되게 설정해주겠습니다.

![image.png](../../%EC%A0%80%EB%B2%88%EC%A3%BC%20%EB%82%B4%EC%9A%A9%20%EB%B3%B5%EC%8A%B5%20+%20%EA%B3%BC%EC%A0%9C%20%EB%B0%9C%ED%91%9C/%EC%9A%94%EA%B8%88%EC%A0%9C/image%203.png)

`켜기` 를 눌러주세요.

![image.png](../../%EC%A0%80%EB%B2%88%EC%A3%BC%20%EB%82%B4%EC%9A%A9%20%EB%B3%B5%EC%8A%B5%20+%20%EA%B3%BC%EC%A0%9C%20%EB%B0%9C%ED%91%9C/%EC%9A%94%EA%B8%88%EC%A0%9C/image%204.png)

`자동 충전 켜짐` 이 나오면 성공입니다.
