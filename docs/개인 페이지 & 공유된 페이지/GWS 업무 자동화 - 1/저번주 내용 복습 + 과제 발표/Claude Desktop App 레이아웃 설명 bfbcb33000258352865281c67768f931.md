# 작업할 폴더 열기

![image.png](Claude%20Desktop%20App%20%EB%A0%88%EC%9D%B4%EC%95%84%EC%9B%83%20%EC%84%A4%EB%AA%85/image%203.png)

Claude Code가 작업할 폴더를 열어주겠습니다.

![image.png](Claude%20Desktop%20App%20%EB%A0%88%EC%9D%B4%EC%95%84%EC%9B%83%20%EC%84%A4%EB%AA%85/image%204.png)

빈 폴더를 만들고 선택하면 해당 폴더 이름이 폴더 선택 아이콘에 나오는 것을 확인할 수 있습니다.

그 후에 Claude Code에게 원하시는 요청을 해주세요.

# 권한 우회 모드 허용하기

![image.png](Claude%20Desktop%20App%20%EB%A0%88%EC%9D%B4%EC%95%84%EC%9B%83%20%EC%84%A4%EB%AA%85/image%205.png)

Claude Code는 파일 수정, 명령어 실행 등 실제 컴퓨터 작업을 수행합니다.

기본적으로는 안전을 위해 작업마다 사용자의 허락을 요청합니다.

하지만 실습 중에는 반복적으로 허락을 눌러야 하는 불편함이 있기 때문에, 강의에서는 '권한 우회 모드'를 사용합니다.

<aside>
⚠️

**주의:**

- 이 모드는 모든 작업을 자동으로 실행합니다.
- 개인 PC에서 사용할 때는 중요한 폴더에서는 사용을 권장하지 않습니다.
</aside>

![image.png](Claude%20Desktop%20App%20%EB%A0%88%EC%9D%B4%EC%95%84%EC%9B%83%20%EC%84%A4%EB%AA%85/image%206.png)

사이드바의 사용자를 누르고 `설정` 창을 열어줍니다.

![image.png](Claude%20Desktop%20App%20%EB%A0%88%EC%9D%B4%EC%95%84%EC%9B%83%20%EC%84%A4%EB%AA%85/image%207.png)

`권한 우회 모드 허용` 의 토글을 켜주세요.

![image.png](Claude%20Desktop%20App%20%EB%A0%88%EC%9D%B4%EC%95%84%EC%9B%83%20%EC%84%A4%EB%AA%85/image%208.png)

이제 Claude Code 창으로 다시 돌아와서 프롬프트 밑에 있는 모드 설정을 클릭해보면 `권한 건너뛰기` 가 보이는 것을 확인해보실 수 있습니다.

![image.png](Claude%20Desktop%20App%20%EB%A0%88%EC%9D%B4%EC%95%84%EC%9B%83%20%EC%84%A4%EB%AA%85/image%209.png)

`권한 우회` 를 눌러주시면 됩니다.

![image.png](Claude%20Desktop%20App%20%EB%A0%88%EC%9D%B4%EC%95%84%EC%9B%83%20%EC%84%A4%EB%AA%85/image%2010.png)

사진처럼 `권한 건너뛰기` 가 보이면 성공입니다.
