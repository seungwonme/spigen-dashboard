# Supabase

# Supabase란?

Supabase는 웹사이트나 모바일 앱을 만들 때 필요한 '백엔드'(서버 측 기술) + DB를 쉽게 구축할 수 있게 도와주는 도구예요.

2019년에 출시된 이후 빠르게 성장하고 있는 서비스입니다. 비슷한 도구로는 구글에서 개발하고 운영하는 Firebase가 있습니다.

<aside>
💡

**쉽게 설명하면:**

웹사이트나 앱은 우리가 보는 부분(프론트엔드)과 데이터를 저장하고 처리하는 부분(백엔드) DB 으로 나뉘어요. Supabase는 이 중 백엔드를 쉽게 만들 수 있도록 도와줍니다.

</aside>

# Supabase의 특별한 점

### 1️⃣ 오픈 소스 기반

Supabase는 완전히 오픈 소스로 제공됩니다. 이것은 코드가 공개되어 있어 누구나 볼 수 있고, 필요하다면 수정해서 사용할 수 있다는 뜻이에요. 마치 요리 레시피를 공유하는 것처럼, 개발자들은 Supabase의 '레시피'를 보고 자신의 필요에 맞게 조절할 수 있습니다.

### 2️⃣ PostgreSQL 데이터베이스 사용

Supabase는 PostgreSQL이라는 강력한 데이터베이스를 기반으로 합니다. 데이터베이스는 모든 정보를 저장하는 곳인데, PostgreSQL은 세계에서 가장 신뢰받는 데이터베이스 중 하나예요.

## Supabase로 무엇을 할 수 있나요?

### 1️⃣ 로그인 시스템 만들기 (Authentication)

웹사이트나 앱에서 로그인 기능은 정말 중요해요. Supabase를 사용하면 다양한 로그인 방식을 쉽게 구현할 수 있습니다:

- 이메일과 비밀번호로 로그인
- 구글, 페이스북, 깃허브 계정으로 로그인 (소셜 로그인)
- 전화번호 인증
- 비밀번호 없이 이메일 링크로 로그인 (매직 링크)

### 2️⃣ 자동으로 API 생성하기

API는 프로그램들이 서로 통신하는 방법인데, Supabase는 이것을 자동으로 만들어줍니다.

<aside>
💡

**쉽게 이해하기:** 

API는 레스토랑의 웨이터와 같아요. 손님(프론트엔드)이 주문(요청)을 하면 웨이터(API)가 주방(데이터베이스)에 전달하고, 완성된 음식(데이터)을 다시 손님에게 가져다 줍니다.

</aside>

### 3️⃣ 실시간 기능 (Realtime)

Supabase를 사용하면 실시간으로 데이터 변경사항을 볼 수 있어요:

- 채팅 앱처럼 메시지가 즉시 표시
- 여러 사용자가 동시에 작업할 때 변경사항 바로 반영
- 사용자의 현재 상태 표시 (예: "지금 타이핑 중...")

### 4️⃣ 파일 저장소 (Storage)

이미지, 비디오, 문서 등 모든 종류의 파일을 저장하고 관리할 수 있어요:

- 사용자 프로필 사진이나 제품 이미지 저장
- 동영상 파일 관리
- 대용량 파일을 쉽게 업로드하고 다운로드

### 5️⃣ 서버리스 함수 (Edge Functions)

복잡한 서버 설정 없이도 특정 코드를 실행할 수 있어요:

마치 전기 스위치를 켰을 때만 작동하는 전구처럼, 필요할 때만 실행되고 그 외에는 비용이 들지 않아요.

<aside>
💡

**쉽게 이해하기:** 

서버리스 함수는 필요할 때만 실행되는 작은 프로그램이에요. 

</aside>

### 6️⃣ AI와 연동 (Vector Database)

인공지능 기능을 앱에 추가하려면 특별한 데이터베이스가 필요한데, Supabase는 이를 지원합니다:

- OpenAI, Hugging Face 등의 AI 모델과 쉽게 연결
- 텍스트, 이미지 검색 기능 구현

## Supabase의 장점

### 빠른 개발 속도

- 원래는 일일히 코드로 작업을 해야하는 기능들을 간단하게 구현할 수 있어 개발 속도가 매우 빠릅니다.

### 확장성과 비용 효율성

- 무료 요금제가 있어 월 이용자 5만명 까지는 무리없이 운영 가능합니다.
- 관계형 데이터테이스를 사용하기 때문에 구조가 복잡해져도 쉽게 확장이 가능합니다.

### **AI 통합을 위한 MCP 지원**

- MCP를 지원해줘서 Cursor를 활용해 Supabase를 빠르고 편리하게 사용할 수 있습니다.

## 실제 사용 예시

### 실시간 채팅 앱

Supabase를 사용하면 카카오톡이나 슬랙 같은 실시간 채팅 앱을 쉽게 만들 수 있어요. 메시지를 보내면 상대방에게 즉시 표시됩니다.

### 회원가입 및 로그인 시스템

이메일/비밀번호 로그인, 소셜 로그인, 매직 링크 등 다양한 로그인 방식을 빠르게 구현할 수 있어요.

### 데이터 관리 시스템

온라인 쇼핑몰의 상품 정보, 블로그의 글, 음식 배달 앱의 메뉴 등 모든 종류의 데이터를 쉽게 저장하고 관리할 수 있습니다.

## 요금제 및 제한사항

### 무료 티어

- 500MB 데이터베이스 용량
- 매월 5GB 데이터 전송량
- 1GB 파일 스토리지
- 최대 파일 크기 50MB
- 매월 최대 5만 명의 활성 사용자
- 매월 50만 함수 호출
- 한 계정당 최대 2개까지의 프로젝트만 생성 가능

**주의사항:**

대시보드에서 다시 활성화할 수 있어요.

</aside>
