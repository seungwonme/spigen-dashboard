# Supabase Project란

<aside>
🗣️

**Supabase 프로젝트**는 **개발자가 복잡한 서버 인프라를 직 접 구축하고 관리할 필요 없이, 웹 및 모바일 애플리케이션의 백엔드 기능을 쉽고 빠르게 개발할 수 있도록 지원하는 BaaS (Backend as a Service) 플랫폼 내의 개별 작업 공간**을 의미합니다

</aside>

## Table Editor

![image.png](Supabase%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EB%A7%8C%EB%93%A4%EA%B8%B0/image%205.png)

데이터베이스에 저장되어있는 값들을 수정, 삭제, 생성 등 조작할 수 있는 창입니다. 

실제로 데이터가 잘 반영이 되었나 확인하는 용도로도 쓰이고 데이터를 우리가 만들 프로그램을 통해서 수정하지 못할때나 빠른 수정이 필요할때 사용합니다.

## **Authentication**

![image.png](Supabase%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EB%A7%8C%EB%93%A4%EA%B8%B0/image%206.png)

- 서비스를 이용하고 있는 유저와 인증을 관리할 수 있는 기능입니다. 인증과 관련된 여러가지 설정들을 할 수 있습니다.

![image.png](Supabase%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EB%A7%8C%EB%93%A4%EA%B8%B0/image%207.png)

- 지원하는 소셜로그인의 종류입니다. 간단한 설정과 코드로 복잡했던 소셜로그인을 구현할 수 있습니다.

![image.png](Supabase%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EB%A7%8C%EB%93%A4%EA%B8%B0/image%208.png)

- 회원가입시 보내질 이메일을 설정할 수 있는 부분입니다. 원하는 문구로 변경을 할 수 있습니다.

- Reset database password 버튼은 현재 설정된 데이터베이스 비밀번호를 **새 비밀번호로 초기화(재설정)** 하는 기능입니다.

![image.png](Supabase%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EB%A7%8C%EB%93%A4%EA%B8%B0/image%2011.png)

- Supabase는 데이터베이스에 REST/GraphQL API로 접근할 수 있도록 자동으로 API를 구성해줍니다. 이 API를 사용하기 위한 **URL**과 **인증 키(API Keys)** 정보가 이 메뉴에 있습니다.
