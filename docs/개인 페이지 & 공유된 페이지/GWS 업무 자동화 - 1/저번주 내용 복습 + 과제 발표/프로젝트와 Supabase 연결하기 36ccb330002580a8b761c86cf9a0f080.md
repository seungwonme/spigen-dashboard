# 2. AI Agent와 Connector(MCP)

## AI Agent란

![image.png](%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%EC%99%80%20Supabase%20%EC%97%B0%EA%B2%B0%ED%95%98%EA%B8%B0/image.png)

**AI Agent: 자율적으로 작업을 수행하는 AI 서비스**

1. **캐릭터(Profile/Instructions):** 에이전트의 성격 → System Prompt
2. **메모리:** 이전 맥락을 유지
3. **⭐ 도구**: AI 에이전트가 다른 도구와 상호작용하기 위한 함수 혹은 외부 리소스 → **`AI Agent의 팔 다리`**
4. **모델:** LLM → **`AI Agent의 두뇌`**
    - LLM(Large Language Model): 텍스트를 인식, 생성하는 등의 작업을 수행하는 AI의 한 종류

### 시스템 프롬프트란

[Explore the context window - Claude Code Docs](https://code.claude.com/docs/en/context-window)

시스템 프롬프트(system prompt)는 **AI 모델에게 `역할, 행동 방식, 톤, 제약 조건`을 지정하는 백그라운드용 지침**입니다.

사용자의 개별 질문(user prompt)이 **`무엇을 할 것인가 (What)`**를 제시한다면

시스템 프롬프트는 **`어떻게, 왜 그렇게 해야 하는가 (How, Why)`**를 정합니다.

1. **역할과 페르소나 지정**
2. **행동 규칙과 제약 설정**
3. **일관성과 품질 관리**

# 4. Context7 커넥터 연결하기

**개발자들이 개발하는 방법**

하나부터 열까지 직접 구현하지 않고, 필요한 것을 연결하여 개발을 합니다.

외부 코드(패키지, 오픈소스)들을 이용하며, 해당 코드를 사용하는 방법이 담긴 문서를 **공식 문서(Docs)**라고 합니다.

**Supabase의 공식 문서**

[Database | Supabase Docs](https://supabase.com/docs/guides/database/overview)

- **Context7 커넥터가 없다면:** 사용하는 패키지들의 공식 문서를 들어가서 필요한 코드, 방법을 직접 읽어서 AI에게 프롬프트로 입력
- **Context7 커넥터가 있다면:** Claude Code로 **직접 공식 문서를 읽게함**
    - **LLM의 Hallucination(환각) 방지**

## Context7 커넥터 연결

```json
{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": [
        "-y",
        "@upstash/context7-mcp"
      ]
    }
  }
}

```

# 5. 실습하기

## Supabase 연결

Claude Code에 아래 프롬프트를 그대로 입력합니다.

```jsx
1. Supabase 커넥터를 활용하여 내 프로젝트의 정보를 가져오고 현재 프로젝트와 Supabase를 연결하는데 필요한 정보를 `.env` 에 추가해줘
2. Context7 커넥터를 활용하여 현재 기술 스택에 Supabase를 연결하는 모범 사례를 확인하고 현재 프로젝트에 Supabase를 연결해줘

연결되었는지 확인하는 간단한 테스트 페이지 만들어줘
```

- **API 키와 .env**
    
    <aside>
    💡
    
    ### API(Application Programming Interface)란?
    
    **서로 다른 서비스간 소통하고 기능을 공유**할 수 있도록 도와주는 매개체입니다.
    
    API를 사용하면 개발자가 처음부터 개발하는 대신 다른 서비스의 데이터, 서비스, 기능을 통합할 수 있습니다.
    
    **데이터를 저장하기 위한 데이터베이스가 필요**한데 데이터베이스를 직접 구축하기 보다는 Supabase에서 무료로 제공하는 **Supabase API를 활용하여 노션 데이터베이스**에 사용자의 정보를 받을 겁니다.
    
    `API KEY`란? 
    
    **API를 사용하기 위한 비밀번호**입니다.
    
    아무런 증명없이 사용할 수 있는 API도 있지만 **Supabase API를 사용하기 위해서는 사용자의 증명이 필요**합니다. **사용자를 증명하기 위해서 `API KEY` 사용합니다.**
    
    > **⚠️ `API KEY` 는 비밀번호와 똑같습니다. 다른 사람들에게 노출하지 않도록 주의해주세요.**
